# DevTools Forensics — техническая справка

> Ведущему. Команде этот файл не показывают — участникам хватит
> [GUIDE.md](GUIDE.md).

Перед командой — публичный лендинг телеграм-бота **ReportDailyBot** и пятнадцать
точек утечки внутренних адресов. Ничего чинить не нужно: задача найти.
Инструмент один — Chrome DevTools. Прогресс двигает ведущий, вводя адреса в свой
дашборд под диктовку Капитана.

## Запуск

```bash
cp .env.example .env
docker compose up --build
```

| Адрес | Кому |
| --- | --- |
| `http://<ip>:8080` | **команде — только эту ссылку** |
| `http://<ip>:7070` | внутренний контур, находится сам |
| `http://<ip>:9090` | дашборд ведущего |

Порты разведены намеренно: `8080` и `8081` рядом путаются на глаз, а команда всю
игру сравнивает домены в колонке Domain.

Раздать команде: `hostname -I` → откройте лендинг по адресу машины и отправьте
ссылку. Адрес контура подставится сам. Если в `.env` заполнены
`STAND_PUBLIC_HOST` и `CORP_ORIGIN` (режим локальной отладки) — очистите их.

## Стек

- **Backend** — NestJS. Один образ на три роли (`APP_ROLE=public | corp | host`).
- **Лендинг** — обычный сайт: HTML, CSS и TypeScript, который бэкенд собирает
  esbuild'ом при старте. Не React осознанно: бандл фреймворка в мегабайт утопил
  бы поиск по Sources.
- **Дашборд** — React 18 + Ant Design 5 (Vite), отдельный бандл.
- **Инфраструктура** — Docker Compose: `public`, `corp`, `host` и MongoDB для
  состояния игры. Порт базы наружу не публикуется.

| # | Категория | Панель DevTools | Слож. |
| --- | --- | --- | --- |
| 1 | HTML Form Action | Elements | ★ |

| 3 | Медиа с корп-хоста | Network → Img | ★★ |
| 4 | LocalStorage | Application → Local Storage | ★★ |

| 7 | Runtime Config | Console | ★ |

| 9 | Over-fetching | Network → Response | ★★ |
| 10 | HTTP-заголовки | Network → Headers | ★★ |

Активны всегда все пятнадцать. Что именно спрятано и какими адресами отвечает —
в [SABOTAGE.md](SABOTAGE.md), устройство стенда — в [CONTEXT.md](CONTEXT.md).

## Ключевые решения

- **Стенд прячет утечки сам при старте.** Лендинг собирается esbuild'ом в момент
  запуска: `app.js` без карты исходников и `legacy.js` вместе с ней. Будь карта
  у основного бандла, она развернула бы `admin.ts` — и утечка 6 перестала бы
  существовать как упражнение.
- **Ни одного адреса в хардкоде.** Собираются в рантайме из заголовка `Host`.
- **Контур живой, и каждый его адрес отвечает.** `corp.test.kz` нигде не
  резолвится, поэтому «внутренность» передаётся отдельным сервисом на своём
  порту: `Server: corp-intranet/1.4`, разрешающий CORS и настоящие внутренние
  данные за каждой ссылкой. Открыть найденный адрес и увидеть за ним консоль
  владельца — половина учебного эффекта.
- **Наружу стенд не ходит.** Ни одного запроса за пределы docker-сети: настоящий
  ReportDailyBot дал только легенду.
- **Дашборд не спойлерит.** До находки строка называет только номер и звёзды;
  категория и адрес на клиент не уезжают вообще.
- **Подсказки — часть истории.** Кнопка 💡 пишет в чат от лица команды, ИБ
  отвечает через несколько секунд. Реплики приходят по очереди, видно «кто
  печатает», а в затишье коллеги подают голос сами.

## Структура

```
.
├─ docker-compose.yml         # public 8080 + corp 7070 + host 9090 + mongo
├─ frontend/
│  ├─ site/                   # лендинг (src/legacy/ отдаётся с картой исходников)
│  └─ host/                   # дашборд: React + antd
└─ backend/src/
   ├─ main.ts                 # выбор роли по APP_ROLE
   ├─ public/ corp/ host/     # три роли
   └─ internal/               # СПОЙЛЕР: реестр утечек, сборка, игра, чат
```

`internal/leaks/registry.ts` — единственный источник правды: из него строится
сайт и по нему же проверяются ответы.

## Про данные

Имена обезличены под персонажей кино. Бинарных файлов в репозитории нет —
картинки, включая анимацию, генерируются как SVG, интернет стенду не нужен.
Прогресс живёт в MongoDB и переживает `docker compose down`; полный сброс —
кнопкой на дашборде или `docker compose down -v`.
